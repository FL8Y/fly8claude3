# FLY8 Clone logo assets

These SVGs are the canonical vector exports for the current FLY8 Clone dual-channel identity mark.

- `FLY8_Clone_Logo.svg` — presentation layout: white canvas, dark rounded-square tile, centered mark.
- `FLY8_Clone_Launcher.svg` — 1024×1024 full-bleed launcher artwork.
- `FLY8_Clone_Adaptive_Foreground.svg` — transparent foreground layer with transparent negative-space channels.
- `FLY8_Clone_Adaptive_Background.svg` — dark navy/black background layer.
- `FLY8_Clone_Adaptive_Monochrome.svg` — single-color themed-icon foreground.

## Design intent

The mark is one asymmetric blue mass with two broad negative-space lanes. The shared left source implies one app instance splitting into parallel instances. The shape avoids stacked app cards, a literal eye/camera, a stock infinity mark, UI window controls, and decorative cyberpunk effects.

The established FLY8 palette is used: near-black `#000001`, surfaces `#010205` / `#01132A`, primary blue `#176E94`, deep blue `#01304C`, and light accent `#FCFDFD`.

## Validation status

The source SVGs are scalable. The working artifacts include 1024px renders, actual 24px / 32px / 48px downscales, grayscale and monochrome previews, and circle / rounded-square mask previews. These are visual design checks, not a substitute for installing the icon in the target Android launcher. No independent user study or formal trademark clearance is claimed.
